# Анализ температурных данных

Домашнее задание по прикладному Python: анализ исторических температур и мониторинг текущей погоды через OpenWeatherMap API.

## Функции

- Загрузка исторических данных (CSV)
- Выявление аномалий (±2σ от скользящего среднего)
- Сравнение текущей температуры с исторической нормой
- Интерактивные графики (Plotly)
- Распараллеливание анализа по городам
- Сравнение синхронного и асинхронного API-запросов
- Карта с текущей погодой
- Сравнение температур в двух городах
- Экспорт результатов в CSV

## Использование

1. Получите API-ключ на https://openweathermap.org/
2. Загрузите `temperature_data.csv` или используйте предзагруженные данные
3. Введите ключ и выберите город
